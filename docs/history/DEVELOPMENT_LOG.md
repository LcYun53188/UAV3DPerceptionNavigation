## 2026-10-15：脚本、文档整理与功能分批提交

审计全部第一方文档与脚本，8 个 Python 构建器统一迁入 `scripts/build/`，原路径保留相对符号链接。6 个绑定 SDK 凭据的构建器保持字节一致，修正共同构建器和 PX4 构建器的目录解析／导入；PX4 执行显式增量构建并重新校验构建凭据，默认及实验 SDK 契约保持有效。运行器和共享模块保留原导入布局，目录区分可执行入口、共享实现与验收输入。

Pocket 控件表统一由面板手册维护；实体 USB／legacy-usb、纯光流和 VIO／EGO 操作手册明确分工。旧 Stabilized／SC 高档结束提案移入[历史方案](POCKET_SC_DESIGN_2026-10-13.md)，避免与现行 Acro／手动干预规则冲突。验收报告和 `scripts/test_*` 继续仅本地保存，包内测试随功能提交；受管 vendor 工作树不纳入普通源码批次。

整理后回归 699 项通过、1 项可选 uinput 检查跳过，EGO CTest 4 项通过；新旧构建路径均从工作区外完成导入及帮助检查，文档目录、链接、脚本语法与 Git 可见性检查通过。分批边界为 VIO／构建、EGO／场景、虚拟面板、无 GNSS 任务控制、文档／目录工具；本轮不执行新的自动飞行或推送远端。

## 2026-10-15：完全无 GNSS 与 SC 手动干预

用户最新规则覆盖此前手动 SD 使用全局 RTL 的方向：手动／定点 SD 均原地慢降，自动 SD 通过 EGO 返回 PX4 局部 Home；自动 SC 为起飞准备、执行任务、手动干预。干预先停止原任务，再交给原生 VIO Position；回到执行档后确认 Offboard、停止并从当前位置重新规划，根任务／起点／截止时间保留。显式交接要求摇杆和油门居中，原生降落承诺不可撤销。

回归 699 项通过、1 项可选 uinput 检查跳过；已构建更新后的 BT。手动／定点实际慢降通过；37c22427 完整任务返回真实局部 Home 并落地上锁，独立审计 12 项通过，实际最小障碍间距 1.048 米。253a1cb1 提前结束返航通过；2b47085a 实际手动干预位移 0.720 米后恢复原任务并返航落地，独立审计 12 项通过，实际最小间距 1.069 米。前轮 0342c7e3 虽完成任务，真值到点误差 0.328 米超限，保留失败，重复运行精度稳定性未验收。实际飞行用例与验收结果见[无 GNSS 验收报告（本地）](../validation/simulation/2026-10-15-no-gnss-return-acceptance/REPORT.md)。虚拟摇杆验收不代表实体 Pocket 或实机测试；旧策略的成功记录保留历史适用范围。

## 2026-10-15：按模式分流 SD 返航与 PX4 Home 基准

手动档 SD 改为请求 PX4 原生 RTL，定点档保留原地慢降，自动档经 EGO 返回 PX4 实际局部 Home 后降落。自动返航点与任务起点分开，记录原始 NED、转换后的 ENU 及实际 RETURN 目标；返航期间 Home 改动或局部坐标重置会终止旧计划。手动 RTL 需飞控确认的全局位置和 Home，当前无地理参考的 VIO 仿真会拒绝该请求。

主机回归 670 项通过、1 项可选 uinput 检查跳过。启动验证发现首次就绪前的时钟暂停误锁存及地图绑定进程晚启动时的接收间隙，已分别改为等待首次完整稳定资格、提前创建 DDS 参与者并延后地图绑定；首次就绪后的时钟保护与原有源新鲜度限制保留。最新完整任务在扫描后因目标制动包络内 3 个占据体素拒绝准入，正常降落上锁，尚未执行返航；完整飞行验收结果和失败证据见[返航点策略报告（本地）](../validation/simulation/2026-10-15-px4-home-return/REPORT.md)。旧策略静态绕障通过不能替代这次 PX4 Home 策略的验收。

## 2026-10-15：Pocket、VIO 主定位与真实静态绕障

无 GNSS Gazebo/PX4 自动任务已完成真实双目／IMU VIO、前向深度建图、EGO 绕箱、到点悬停、返航、最终悬停、原生慢速降落及上锁。运行 `99222fb8-7cc7-428e-a175-685c0aa1fbd6` 的任务、源连续性、独立几何验收和进程清理均通过；实际导航／返航最小障碍间距 0.978 米，高于 0.8 米机体／跟踪包络。前进／返航最大估计跟踪误差为 0.136／0.186 米，保留原 0.3 米限制。

修正包括隔离 SDK 的双精度 Schur 边缘化、EKF 延迟融合新鲜度检查、扫描与 B 样条跟踪解析前馈，以及目标／返航高度的实际地图包络准入。VIO 主定位保持 EV 位置／高度／航向必需，允许 PX4 拒绝箱顶测距创新并如实记录辅助融合状态；地面联合融合检查与原始源保护保留。默认 SDK 安装未替换。

回归检查 616 项通过、1 项可选 uinput 检查跳过。两次路径使用经碰撞／动力学校验的 A* 种子回退，不能称为优化器收敛；一次静态仿真成功也不代表动态避障、实机或全局协方差资格通过。虚拟 Pocket 的 QGC 输入／地面就绪另行记录。命令见[操作手册](../flight/VIO_POCKET_AVOIDANCE.md)，原始失败、轨迹图与验收指标见[验证报告（本地）](../validation/simulation/2026-10-15-vio-fusion-diagnostics/REPORT.md)。

SDK16＋MTF-01 无 GNSS 完整名义任务已完成起飞、同机深度建图、EGO 导航、悬停、返航和降落上锁。该轮 VIO／PX4 最大定位误差为 15.20／15.00 cm，到点误差为 9.71／8.39／9.66 cm；动态轨迹跟踪并非全程小于 20 cm，主动绕障、独立原生空中 aid 回执与全局协方差资格尚未验收。详见 [20 cm 验收记录（本地）](../validation/simulation/2026-10-13-nav-20cm/REPORT.md)。这属于仿真证据，实机飞行仍待验证。
