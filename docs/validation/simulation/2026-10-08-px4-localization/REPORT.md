# PX4 定位输入门控回归（2026-10-08）

本批是 S3 定位输入安全门控，不是 EGO/PX4 感知导航整体验收。原算法仿真在 domain 68
保持运行，地图和 HOLD 状态保留；USB DM-FC01 未收到本批控制输出。PX4 回归固定
v1.16.2、x500_7、domain 78、随机 Gazebo 分区、W0 known_region_control；监督器 QGC
禁用 USB 自动连接，回归期间 fuser 检查实机 ttyACM0 没有读者。

## 修改与约束

网关此前只要求本地位置新鲜，动态 TF 所依赖的 VehicleOdometry 未纳入健康门控。
现在要求其帧转换有效，且接收、发布源时间与 timestamp_sample 采样年龄均满足已有
0.1 s 门限，未来容忍 0.05 s，采样时间非零；未放宽健康/定位门限。

绑定 xy/z/vxy/vz/heading 与 odometry reset_counter 六个计数。任务或最终保持拥有
参考期间任何变化立即锁存，阻止后续里程计/动态 TF 发布和新任务准入；旧 TF 缓存
不能撤回，下游仍需检查时效/会话。重置后重新建立监督器会话，不自动恢复旧轨迹。
最终保持故障撤销保持所有权，原根结果不被覆盖。只读聚合器同步补充速度重置检测。
