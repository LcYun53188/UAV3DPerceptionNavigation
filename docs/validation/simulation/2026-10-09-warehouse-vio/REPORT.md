# 仓库场景与 VIO 前置检查

新增仓库场景和分阶段验收入口，实际运行六轮，均保持 PX4 未解锁。场景、纹理、飞行区静态净空检查通过；VIO 源/融合/运动前置验收未通过，因此仓库悬停、航点导航、避障均为 NOT_RUN。没有以原 W0 飞行成功替代本场景验收。

## 已实现

- 通用 14×14 m、6 m 高室内布局：墙、隔间门洞、立柱、货架实体、箱体及纹理地面。门洞 2.4 m 宽、3 m 高。全部实体带碰撞体。
- 固定随机种子生成场景。实际相机画面暴露稀疏墙面纹理后，新增 PNG 多尺度角点材质；SDK 只消费双目/CameraInfo/IMU/静态外参，纹理不产生位姿。
- 预定 x/y ±2 m、z≤3 m 的首批无障碍位置范围。机体/跟踪/制动余量分别 0.5/0.3/1.2 m，展开至 x/y ±4 m、顶部 z=3.8 m，逐一核对所有障碍 AABB。地面是允许接触的支持面，静态几何不证明实际制动或定位准确。
- `--scene warehouse` 同时支持原未解锁同机融合与独立运动载台入口；默认 planar/layered 和原 W0 控制 hash 不变。
- 只读仓库验收器核对资产/纹理摘要、净空、原始通过状态、持续 READY 与运动误差。无有效运动指标时输出失败检查，不抛类型错误。始终 `flight_authorized=false`。
- 待接入航点 recipe：起飞 1.5 m→悬停 15 s→(1.25,1,1.5)→悬停 10 s→(-1.25,1,1.5)→返航→悬停 5 s→降落。

## 原始实测结果

前三轮使用稀疏视觉特征，中途新增角点纹理，因此不是严格单变量受控实验。模型/世界/布局/标定/输入摘要在各 manifest 中冻结；两种场景资产均保留。

所有轮次 `cleanup_confirmed=true`，PX4 arming_states=[1]。运动轮没有 FMU 输入；两轮融合只有 EV 写入，无飞行命令。复跑共有 2943 个 SDK 位姿，末帧原始方差对角线约 [0.0552,0.3939,0.2814,0.00261,0.01035,0.01281]；坐标变换后的归一化仍须满足原方差门限，不截断或伪造质量。

实际图像确认角点 PNG 材质已加载；这不证明 SDK 观测可用或漂移受控。没有证实静止初始化、纹理、远距离视差、调度或 IMU 误差中的单一根因。一次 ROS 接收异常未在复跑中重现，保留原堆栈，不宣称已修复。
